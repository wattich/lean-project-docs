## เริ่มงานทุกครั้ง
1. อ่าน `docs/STATUS-NOW.md` (สถานะล่าสุด สั้น เขียนทับ)
2. งานหัวข้อไหน ให้ grep `docs/decisions/<หัวข้อ>.md` ก่อนตัดสินใจเรื่องที่อาจตัดสินไปแล้ว
3. `docs/history/` เป็นประวัติ ให้ grep เท่านั้น ห้ามอ่านทั้งไฟล์

## กติกา (5-10 ข้อ เขียนเฉพาะที่ต้องรู้ทุกงาน)
1. ห้ามใส่ความลับ (รหัส, token, connection string, IP ภายใน) ในโค้ด เอกสาร หรือ commit ให้อ้างชื่อ env เท่านั้น
2. ห้ามใช้ข้อมูลจริงของลูกค้า/พนักงานใน test และเอกสาร ให้ใช้ข้อมูลสมมติ <ช่วงรหัสสมมติ>
3. ค่าที่ปรับได้ต้องเป็นค่าตั้ง (settings) ห้าม hardcode
4. งานหน้าจอ: ทำต้นแบบก่อน แล้วหยุดรอคนตรวจ
5. ทำทีละชิ้นเล็ก ทดสอบผ่านแล้ว commit 1 ครั้ง ห้าม push/force-push เอง (ถ้าทีมกำหนด)
6. <กติกาเฉพาะโปรเจกต์ เช่น ฐานข้อมูลที่ห้ามแตะ, ระบบเดิมอ่านอย่างเดียว>

## จบงานทุกครั้ง
1. การตัดสินใจใหม่: ต่อท้ายลง `docs/decisions/<หัวข้อ>.md` (ห้ามแก้ของเดิม)
2. เขียนทับ `docs/STATUS-NOW.md` ไม่เกิน 60 บรรทัด
3. commit แล้วแจ้งว่าพร้อม /clear
